# DoSJE NEXUS — Monitoring Portal v2

## Included
- Attractive responsive command-centre UI
- Home, Projects, Live CCTV, Inspections, AI Analytics, Alerts, Random VC, Reports
- Hash-based navigation: clicking any sidebar/menu/home card changes the page
- Login
- New registration
- SQLite database
- Express backend
- Random inspection assignment
- Geo-tagged inspection submission
- Evidence upload
- Alert resolution
- Demo fallback if backend is not running

## Run
1. Install Node.js 18+.
2. Open this folder in terminal.
3. `npm install`
4. `npm start`
5. Open http://localhost:3000
